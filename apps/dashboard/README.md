# Abiyasfaw Dashboard

Next.js operations console for Abiyasfaw's blind dating workflow.

## What is included

- Compatibility queue for blind profiles
- Cultural prompt library
- Reveal guardrails before photos open
- Human safety review board
- Hosted date room planning

## Run

```bash
npm run dev
npm run build
npm run lint
```

From the repository root:

```bash
npm run dashboard:dev
npm run dashboard:build
npm run dashboard:lint
```
